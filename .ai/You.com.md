# You.com | Documentation

> Search, Contents, and Research APIs that give your AI app real-time web intelligence. Start with free credits.

> ## Instructions for AI Agents

- For clean Markdown of any page, append `.md` to the page URL
- For a complete documentation index, see https://you.com/docs/llms.txt
- For full documentation content in one file, see https://you.com/docs/llms-full.txt
- For section-specific indexes, append `/llms.txt` to any section URL
- For AI client integration (Claude Code, Cursor, etc.), connect to the MCP server at https://you.com/docs/_mcp/server
